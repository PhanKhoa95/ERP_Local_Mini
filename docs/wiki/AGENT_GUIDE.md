# Agent Guide

1. Đọc Context Map và tài liệu nguồn liên quan trước khi hành động.
2. Không sửa hoặc xóa tệp trong `00_Inbox/`.
3. Tạo RAW, SPEC và TECH từ template đúng lane; không tái sử dụng ID.
4. Luôn ghi `source_ids` để giữ truy vết ngược.
5. Không tự chuyển SPEC sang `approved`.
6. Không viết code chỉ vì thấy SPEC đã duyệt; cần handoff có allowed paths và lệnh validation.
7. Không ghi secret, API key, token, dữ liệu riêng tư hoặc payload sản xuất vào Wiki.
8. Chạy Project Wiki validator trước khi bàn giao.
