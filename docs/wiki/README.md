# Project Wiki Context Map

Đây là nguồn sự thật dạng tệp cho yêu cầu, đặc tả đã duyệt và tài liệu kỹ thuật của dự án.

## Luồng tài liệu

```text
00_Inbox -> 01_Raw_Requirements -> 02_Refined_Specs -> 03_Technical_Docs
```

- Đọc `AGENT_GUIDE.md` trước khi chỉnh sửa.
- Không sửa hoặc xóa nguồn trong `00_Inbox/`.
- Giữ `source_ids` để truy vết `RAW -> SPEC -> TECH`.
- Chỉ con người hoặc vai trò được ủy quyền mới đặt SPEC thành `approved`.
